原验收矩阵 `reference/original/03_ACCEPTANCE.md` 是基线，完整保留：C01–C08、N01–N06（每场景三次）、I01–I08、A01–A12、G4 五次、G5 两次和 fresh replay。另加本页 L/V 补充反例。

先生成可读覆盖账：每个原 ID 对应测试入口、前置条件证明、实际动作证据、判定器、状态及缺口。A09 与 A10 分开，不能一个 `A09A10=true` 同时抵两项。缺失、未执行、异常、跳过都不算 PASS；一个测试可以服务多个原条目，但每个条目的断言必须分别成立。报告要能看到 required/pass/fail/blocked/not_run 总数，不能只报告已挑选测试的成功率。

## 2. 生命周期补充门（假进程优先，之后一套实机确认）

| ID | 必须构造的场景 | 拒绝假成功的判定 |

| L03 | 管理器在 spawn 前后、状态提交前后崩溃，子进程仍活 | 后继只能接管/清理原实例或阻断；实际实例数不增加；必须测创建后落盘前窗口。 |

假测试不能拉 Minecraft，并发必须真的跨进程。假进程稳定后有限实机验证启动/幂等/停止/重启/身份与数量；不要求为了证明故障注入而十次杀真实游戏。

## 3. 必须修正的原 fixture

**I01/A08：非快捷栏来源。** 初始断言工具/食物/方块分别在主包索引≥9的不同槽，快捷栏无同款；再执行正式动作。仅注释“主包”或 give 后默认位置不合格。读初态、迁移轨迹和最终位置/组件。

**I02：真实增量。** 分别移动1、7、31件，包含目标已有10件再移7件、合并空间不足、满堆、源预留与目标保护。记录源/目标基线、最终量及 cursor，不只 total不变或目标≥N。

**I03：真实选择。** 两件同 ID/不同组件，在不同位置；要求移动不在目的槽的指定件，保留另一件。既校验两件数量，也校验组件与位置；已有一把在目的槽的 no-op 不得冒充这一项。

**I05：真正满包/满容器/禁插入。** 独立确认主包与快捷栏36槽真实占用、没有能容纳本次产物的合并空间；另测容器满和能取不能放的槽。六槽已用不是满包。若配方消费腾出容量，应选择不会意外产生有效容量的测试条件，先确认前置场景。

**I06/C06/A11：换屏和光标。** 在拿起物品、部分拆分、取出产物尚在cursor三个阶段注入取消/断线/换屏。恢复只处理自己可证明的状态；不能对另一容器继续按旧编号操作。

**N01/N03/N06：几何是真的。** N01台阶要高于地面，轨迹确实跨越；N03起点放在U内部，使合法路线必须先远离目标，不能从外侧直接绕过就声称验证了退让；N06目标本身是可站格，只是被封闭，不能用实心目标格替代不可达路径场景。

每个 fixture 都要在 armed 前独立断言关键初态；设置命令失败、读取不完整或场景不成立，判定本用例无效/失败，不进入计分。动态通路/外部 actor 改动是预先声明的故障注入，不得中途改成帮助 Bob 过关。

## 5. C组必须在接入导航与事务后的最终候选重跑

原C02早于Baritone接入，不能迁移为本次停止证明。分别记录取消发出、客户端处理、导航停止、最后业务点击、清理完成、回执到达及已发生效果；区分网络延迟和客户端10 tick收尾要求。

## 6. G4原核心链，不能降级为“给材料合成”

固定候选C、依赖与运行配置；预先写定B01–B05矩阵：两次橡木、两次第二树种、一次非默认快捷栏/堆叠布局，至少两种局部地形。非默认布局由运行中真实调槽产生，初始仍是空主包/快捷栏/装备/副手/cursor，没有预给工具/食物/工作台。

树形与石面可以在测试准备期布置在局部导航范围内；测试观察器先证明初态。这不是用长距离找资源测导航。armed之后只能正式语义动作：采木拾取→原生2×2→放置/打开工作台→3×3木镐→木镐采石拾取→3×3石镐→重新打开工作台→终态检查。

每次默认12分钟，五次完整连续通过。同一候选才可计为5/5；中途改生产代码、依赖、影响行为配置、候选、世界/初态补救，必须保存失败并重新开始完整五次集合。允许候选之前修fixture，但不能为了规避真实缺陷放宽场景或偷偷赠物。

终点同时拥有木镐和石镐、材料来自本次合法采集、工作台精确存在且可再次打开、光标空、导航和动作都已停止、无未结unknown。空包开始后禁止give、时间/难度修改、teleport、kill清怪、恢复存档或直接服务端写物。预给圆石的A02只能证明合成，不能代替这里的采石。

## 8. 不允许省略的验收器反测试

对真实已脱敏证据的副本作离线变异，证明以下一律使checker拒绝：缺必需ID/重复ID、空results、只有pass布尔、NOT_RUN被计成功、混run/world/session/产物、数量不守恒、产物仅在cursor、同类替代目标、错原生执行路径、未知结果未对账、五次缺一次/中途换候选、管理员补救记录。

这些变异只能在清晰标注的synthetic目录，不能覆盖原始证据，也不能作为LIVE成就。判定器需从原始事实计算，而不是从“server_authoritative…”文字或作者布尔读结论。

## 身份与范围

- 当前基准确为ecab2f6之后的本轮分支，未混入旧0.8/含秘密历史；实际代码与报告C一致。

## 进程安全

- 管理器崩溃但子进程未死、state损坏/丢失、CIM失败、PID复用、stop失败均有非空反例。
- 观察实际实例数而不只state条目数；假测试独立命名空间；跨进程并发而不只是线程。
- stop失败/另端成功不清异常预算；显式停止后无复活；受管子进程有归宿；无误伤正常客户端。

## 终态与事务

- cancel/pause/timeout/lease/control/game loss真的停止库内导航、转向与调度；不只KeyBinding=false。
- 玩家/容器/工作台screen身份及槽位归属正确；旧screen和同类另一目标不能接续点击。
- 合成按本次产出而非批次数；移动按本次增量；物品组件/保护、源/目标/cursor共同核对。
- 放置库存消耗进入判定，且能区分外部actor；食物消费有本次使用证明。
- 采集不偷换同类目标，不把掉落未入包当获取；未知结果不自动再执行。

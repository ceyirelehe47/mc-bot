> **保留 Bob 的真实客户端身份；成熟导航组件做受控执行；建立最小共享背包/GUI 事务；所有成功由实际状态证明；先重复跑通木器到石镐，再验证完整过夜。**

## 3. 终点与门禁

| 门 | 本轮交付 | 进入下一门的条件 |
|---|---|---|
| G0 | 固定源码/产物/环境身份，隔离测试世界，凭证与可重建基线 | 能从可追溯源码构建并启动；未解决的安全问题不被掩盖 |
| G1 | 可靠命令生命周期、清输入、取消/断线、真实回执 | 失败提交不抢占无关执行；旧消息不产生新动作 |
| G2 | 成熟导航接入与工作站位 | 多地形重复通过；不可达诚实失败；默认不破坏地形 |
| G3 | 最小背包/容器事务、原生合成、准确放置、有效进食 | 槽位与物品语义一致；实际变更证明；负例不能假成功 |
| G4 | 空背包→采木→原生合成→木镐→采石→石镐 | 同一最终候选 5/5 完整运行；不修改代码、不人为补救 |
| G5 | 有界 LLM 游玩与完整过夜、清洁重建复验 | 两个自然场景均过夜且保存进度；fresh build 重跑核心链 |

G0–G3 是实现与基础测试；G4 是固定流程验证；G5 才是有界游玩。**不能用继续放跑游戏替代修复基础动作。**

## 4. 实施自由与禁止事项

你可以拆分现有巨型类，新增内部模块，调整私有协议及工具参数，编写 fixture、测试和采集器，并修复与目标直接有关的 installer/build 路径。参数语义变更必须让调用端同步，旧调用明确拒绝或显式兼容。

你不能擅自切换 FakePlayer、改为服务器辅助合成、迁移 Minecraft 版本、恢复 DSH、增加铁器/冶炼/农业/战斗/下界任务，也不能通过删除失败测试宣称回归通过。

历史 0.8 任务书里的“仅改几个文件”“DSH 工具恰好 29”“旧 attestation 必须先收到”不作为本轮的机械门禁；本轮允许修执行层。但它们保护的身份、可见性、租约、Screen 与真实回执语义继续保留。不要拿历史 source-string 测试逼迫新实现保留错误结构。

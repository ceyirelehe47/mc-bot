# 05｜Agent 自主执行与停止规则

## 1. 授权范围

在本轮新分支上自主设计、修改、构建、测试、修复；使用隔离测试世界自行操作 Bob。允许读取官方文档和锁定依赖，允许新建内部模块和测试，允许删除/禁用不合规的 Real Client 服务端合成入口。

开始时将合理的内部设计选择写入 `templates/DECISIONS.md` 的同类工作记录，然后直接实现。该记录是追踪，不是需要用户逐项批准的设计提案。

允许 subagent 分工研究、编码和独立审查；所有游戏 LIVE 调度仍由唯一协调者持有控制权。不同时运行多个“玩游戏”的脚本争夺同一个 Bob。

本轮不向 Notion 写文档，不代用户切换产品路线，不重写共享远端历史，不动真实玩家客户端/生产世界。普通代码和测试决策不需要再次问用户。

## 2. 必须区分的三种模式

**开发模式**：可以修改代码、fixture、测试装置，验证具体假设；不是游戏成就。

**计分验证模式**：候选 C、依赖、运行配置固定。可以自动恢复本用例初态，但 run 开始后禁止改生产代码、换 jar 和管理员补救。

**有界 LLM 游玩模式**：只在 G4 完成后启用。模型只能通过正式语义接口决策；失败由结构化证据触发停止/重新规划。游戏模型不能在计分中同时修改执行器。

三个模式都记录身份与起止。不能把跨版本调试时的零散成功拼成一条端到端记录。

## 3. 预算与避免无效放跑

本包默认给这一轮 **最多 24 小时主动实施/验证窗口**，从 G0 开始由协调者记时；这是本轮执行上限，不是已证明的完成耗时。不包括等待用户处理外部账户凭证的时间，但等待必须停止占用相关运行资源。

导航兼容性：首选候选最多 2 小时做可运行小切片。到时必须有成功的最小启动/移动/取消证据，或有带日志的确定阻塞和替代决策，不能继续无目标调版本。

同一个关键失败最多 3 轮**有新假设、有对应代码修复、有最小复现复测**的尝试。单纯加 timeout、换坐标、重启再试不算有效修复。三轮仍失败则阻断相关门；其他独立工作可完成，但不得假装后继 LIVE 已经通过。

计分用例使用 `03_ACCEPTANCE.md` 的限时；不得事后提高到数小时。连续两个相同条件的无进展游戏尝试就停下来诊断，禁止整夜空转脚本。

达到窗口上限：只按实情交付 PARTIAL/BLOCKED 和可续跑点，不伪报通过，也不自行续开“再跑三天”。窗口尚未耗尽且下一步可执行时，不以“做完一个切片”为理由提前结束整个任务。

## 4. 进度记录

至少在每个门完成、每次关键方案变化或连续 60 分钟实施后，更新一份短工作记录：当前门、最新可运行候选、最后成功证据、当前失败根因、下一步。

记录放本轮交付/工作目录，不散落十几份 wood2/wood3/wood4 脚本。保留失败尝试计数，不能每次换文件名就重新计算。

长期目标依赖事实推进，不依赖日志文案和 Python 函数“没抛异常”。异常/状态失败都要检查；`sheltered`、`crafted`、`arrived` 等本地状态由物理结果建立。

## 5. 实现与审查分离

每门完成后，用与编写者不同的审查角色检查：
- 动作是否真的走正常客户端路径；
- 是否有固定槽位、模糊目标和宽松 completed；
- 错误处理是否抢占别的任务；
- unknown、cursor、取消和重连是否有未结效果；
- 测试是不是非空、真实触发目标条件，而不是条件永远没发生。

环境提供独立 subagent 时使用。没有独立执行能力时，由主 Agent 做一次单独标注的二次审查，并如实写明“非独立审查”；不得伪造 reviewer 身份。

审查报告不代替自动化或 LIVE。必须把发现的实质问题修掉，再运行受影响用例。最后仍由用户/ChatGPT 决定接受，不要给自己盖 FROZEN。

## 6. 必须停下等待新的路线授权的情况

- 正常客户端路线需要改成服务端直接 mutation/FakePlayer 才能继续。
- 想升级 Minecraft 版本、取消无透视、放宽 exact-target 或移除安全输入隔离。
- 需要不可逆删除生产世界/用户数据，或需要 force push 清理共享历史。
- 无法安全取得必须的账户权限/凭证。
- 成熟导航首选与一次合理备选均不能满足边界，需要重新决定执行后端。

报告应包含实际障碍，不用“模型不够聪明”替代根因。可以完成安全且独立的部分，但不能偷偷改变路线。

## 7. 不可采用的过关办法

- 用服务器扣料给产物，称“反正没凭空造物所以还是原生合成”。
- 传错 slot 时改传 0，或把指定物品改成随便一个物品。
- 屏幕类型相同就认定目标相同；附近有方块就认定瞄准了目标。
- 参数错误后取消无关执行；无 ACK 就直接宣告执行槽已释放。
- 将导航内部搜索发现的隐藏矿物暴露给 LLM。
- 把测试世界管理员布置算成 Bot 的自主成绩。
- 通过延长等待、重开世界、换种子、重试直到碰巧成功隐藏失败。
- 因框架门过了就提前写 ironage/smelt/农业编排。

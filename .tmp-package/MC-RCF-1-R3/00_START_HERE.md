## 2. 两条工作线，一套最终结论

**实现线**负责：进食实际消费归因、正常入洞／放置／过夜、纯读感知与缓存写入分离、同角色全部实例停机、收尾恢复与真实 Tom’s 转移。

**验证线**负责：运行时身份、原始事实采集、主判定器、正例及语义变异、覆盖分母、重放和独立复核。验证者不得为了让测试变绿而修改生产结果、放宽判定或把缺失事实补成 true。

唯一协调者掌管合并、起停、租约、测试准备和 LIVE。实现者与验证者可用不同 subagent，但不得同时写同一文件、同时操纵游戏。只有一个 Agent 时分阶段完成并明确是二次自审，不虚构独立审查。

内部模块、字段、接口由实现者设计。可以重构必要的驱动、协议、观察、installer 与测试；本包不提供未经 Fabric 验证的生产补丁，不锁死应用 schema。只固定行为、证据含义和验收终点。

## 4. 本轮不可绕过的原则

- 发现候选仍只读；正常接近和转向后，新鲜准星帧才能准入持久机会；不得恢复 sweep 注册、假来源或后台直接写包。
- 正式 G4/G5 开始后不允许管理员推进成功：无传送、给物、设置方块、改时间／难度／天气、清怪、复活、keepInventory 或睡觉跳夜。故障注入仅在预声明的负例运行，不进入成功计分链。
- 只读 oracle 可独立判题，不可给 Bot/LLM 回传隐藏状态或决策建议。查询失败、信息缺失或过期必须是不确定，不得默认安全。
- 摘要和 reason 可以展示，不能替代原始事实；同一最终 checker 判真实正例与其变异副本。不得以“增加 true 字段”或“旧格式全拒”关闭审查。
- 同一宿主机本轮最多一个受管测试 server 和一个 Bob client。GameTest 串行纳入资源调度。普通用户客户端不属于可随意杀掉的测试进程。
- 禁用未验收的 smelt 和旧时代／无限游玩入口。不上铁器、战斗、任意 Mod、新大规划器或替代后端。

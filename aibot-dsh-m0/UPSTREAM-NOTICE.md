# Upstream notices

This bundle contains new experimental bridge sources and patch instructions for pinned
AIBot source files. It does not include a complete AIBot, Minecraft, Fabric or DSH checkout.

Preserve the original projects' LICENSE and attribution files when applying the overlay.
The AIBot metadata inspected at the pinned revision declares MIT; its original LICENSE
file is not replaced by this installer. DSH dependencies retain their original notices.

Source review and version pins are recorded in BASELINES.json and evidence/source-review.json.
No external project is represented as having endorsed or tested this experiment.
